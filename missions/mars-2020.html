📖 Про місію

NASA Mars 2020 (Perseverance) - це сучасна наукова лабораторія, отправлена на Марс для пошуку давніх слідів мікробного життя. Марсохід виконує свою місію в кратері Єзеро, який містить докази давніх озер та річок.

🔧 Основні датчики:

  • RAMI - гастрін для вивчення кисню
  • Mastcam-Z - кольорова гайбун високої роздільної здатності
  • PIXL - рентгенівський спектрометр
  • SHERLOC - лазерний спектрометр для органічних молекул
  • RAD - датчик радіації
  • Drill - буріння до 3 метрів глибини

🎯 Цілі дослідження:

  • Пошук органічних молекул та лосків давного життя
  • Вивчення геології кратера Єзеро
  • Дослідження атмосфери та клімату
  • Тестування технологій для людських місій (MOXIE - виробництво кисню)
  • Збір марсіанських зразків для повернення на Землю

🚁 Ingenuity Helicopter

Perseverance везе з собою вертоліт Ingenuity - перший апарат, що зробив керований політ на іншій планеті. Це демонструє технології для майбутніх дослідження.
