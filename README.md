# Mars

Це освітній веб-проєкт про Марс, який показує красу і факти про Червону планету.

## Ідея
- Односторінковий сайт із марсіанською графікою та анімацією.
- Інтерактивна кнопка для випадкових фактів про Марс.
- Мінімалістичний дизайн у темних тонах із теплими акцентами.
- Секції для основних фактів, місій, кратерів та визначних місць.

## Структура
- `index.html` — розмітка сторінки.
- `style.css` — стиль і візуальне оформлення.
- `main.js` — простий скрипт для динамічних фактів.

## Як запускати
Просто відкрий `index.html` у браузері.
